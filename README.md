# 私人海岛庄园 three.js 场景

东西约 700 米、南北约 400 米的末世自给自足型私人海岛庄园。场景全部程序化生成，没有外部模型或贴图文件，构建产物是一个单页 HTML。支持鸟瞰浏览和第一人称漫游。

## 快速开始

```bash
npm install          # 只安装测试用的本地 three.js（页面本身从 CDN 加载 r160）
npm run build        # 生成 dist/island.html
```

直接用浏览器打开 `dist/island.html` 即可。页面通过导入映射从 jsdelivr 加载 three.js r160，需要联网。

## 操作

| 模式 | 操作 |
|---|---|
| 鸟瞰 | 拖动旋转，右键平移，滚轮缩放；左下角或数字键 1–9 切换视角；H 隐藏界面 |
| 漫游（F 进入） | WASD 移动，鼠标转向，Shift 奔跑，空格跳跃，V 切换第一或第三人称，E 交互，M 小地图缩放，C 下潜，R 回到起点，Esc 暂停（可传送） |

漫游起点在别墅正北门口。

- 可进入或登上：
  - 别墅：一至三层与屋顶，二层后门通阳台。
  - 三座瞭望塔：塔内折返楼梯通到观察室和外圈平台。
  - 游艇：主甲板、上甲板、下甲板客舱和日光甲板。
  - 其他：机库、水闸检修步道、网球场。
- 驾驶：靠近 Cybertruck 或拖拉机按 E 上车；W/S 控制油门、制动和倒车，A/D 转向，空格手刹，V 切换视角，E 下车。
- 游艇：在驾驶台舵位按 E 手动驾驶，按 C 自动巡航。自动巡航会依次开闸、出港、离岸绕岛一周、回港倒车靠泊、关闸，全程约 10 分钟，途中可在船上自由走动。
- 水闸：在闸口瞭望塔一层的闸控室按 E 开关电源；闸门为无围栏下沉式，开启时沉入海底，站在闸顶的人会被移到就近桥墩。
- 游艇登离：靠近浮台按 E 直接登上后甲板，在后甲板按 E 下船；不能直接走上船。
- 坐与躺：所有椅子、沙发、吧凳可坐，床和躺椅可躺（别墅、沙滩、泳池、游艇均有）；按 E 坐下或躺下，按 E 或移动键起身。
- 直升机：靠近 H125 按 E 登机；空格上升、Shift 下降、W/S 前后、A/D 转向、V 视角；按 G 自动飞往别墅屋顶或返回停机坪（超低空），落地后按 E 下机。
- 潜水：任何水域（海、泊港、湖、泳池）按住 C 下潜，可观察鱼群；在泊港里靠近海豚按 E 可抚摸。

## 坐标与约定

- 单位是米，x 向东，z 向南，y 向上；北方是 −z。
- 旋转角遵循 three.js 的 `rotation.y` 约定，矩形有符号距离函数 `rectSD` 用的是同一约定。
- 地形网格为 1 米分辨率，范围 x∈[−380, 380]、z∈[−230, 230]。
- 布局只在 `02_layout.js` 中定义，其他模块都引用 `L.*` 常量。

## 画质分档

启动时自动判定档位，也可以在右下角手动切换，选择会记在本地；地址栏加 `#q=high`、`#q=mid` 或 `#q=low` 可强制指定档位。

| 参数 | 高 | 中 | 低 |
|---|---|---|---|
| 像素比上限 | 2 | 1.5 | 1 |
| 地形网格 | 1 米 | 1 米 | 2 米 |
| 阴影图 | 4096 | 4096 | 2048 |
| 树木密度 | 100% | 80% | 45% |
| 近景草叶半径 | 60 米 | 40 米 | 关 |
| 漫游近景阴影 | 开 | 开 | 关 |
| 云层 | 开 | 开 | 关 |

## 测试

测试需要 Python 3、playwright 和 Chromium。页面中的 CDN 请求会被路由到本地 `node_modules/three`，所以离线也能运行。

```bash
npm run test:terrain   # 关键点高程、道路坡度、崖顶起伏（纯 node，约 1 秒）
npm run test:physics   # 漫游物理：碰撞、栈道、游泳潜水、进入建筑、登船登塔、防攀爬、重置
npm run test:drive     # 车辆驾驶、游艇登船与航行、自动巡航全程
npm run test:perf      # 三角面、绘制调用、分段加载耗时（高档与低档）
python3 tests/shot.py "file://$PWD/dist/island.html" out.png 1920 1080 done 600 "still,clean"   # 鸟瞰截图
```

地址栏的调试参数：
- `still`：只渲染 3 帧后停止，并暴露调试对象；
- `debug`：只暴露调试对象；
- `fp`：直接进入漫游；
- `noworker`：强制在主线程生成。

## 已知取舍

- 没有做环境光遮蔽后处理：它会破坏多重采样抗锯齿，帧率约减半。地形已烘焙遮蔽，树冠也有顶点明暗，可以替代它的大部分效果。
- 建筑上层不可进入，别墅二层只开放阳台。
- 近景阴影每移动 3 米才重绘一次；附近有风机转动时每 0.5 秒重绘一次。

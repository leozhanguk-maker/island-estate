# 开发历程与待办

## 已完成的迭代（按时间）
1. 基础场景：程序化地形、全部设施、道路、植被、动物、游艇、直升机、风机等；鸟瞰视角。
2. 写实度六轮：r147→r160 与后台线程；地表细节纹理与近景草叶；天空云层；叶片面片植被；崖壁冲沟/岩架；跟随阴影；可进入建筑、小地图、潜水、源码包。
3. 第二批需求：Cybertruck 驾驶、游艇内部与驾驶、水闸开关、椰子树+榕树、人物、动物动画、水稻田、栈道改线、别墅三层与屋顶楼梯、塔楼楼梯。
4. 第三批需求：自动巡航（开闸→绕岛→回港靠泊→关闸）、蔬菜/大棚作物、泳池/湖/海水写实（半透明、焦散）。
5. 第四批需求：别墅盆栽（水仙/红玫瑰）、推拉门、精细家具、坐卧系统、iMac 书桌；全部水域可潜、瀑布粒子、鱼群、海豚互动；榕树整株化；游艇按 E 登离、缆绳改拴、舱内精细化与座位；沙滩纯白与连续坡度；H125 复刻与自动飞行；躺椅遮阳伞朝向；塔顶楼板；下沉式无围栏水闸。

## 当前测试基线
- 物理：全部用例通过（别墅到屋顶 22.45 m、东峰塔平台 77.93 m、闸顶 4.53 m 等）。
- 自动巡航：10.4 分钟，零碰撞，回到 (30, 87, yaw π)。
- 直升机：去程 71 s、回程 72 s，精确落点。

## 待办
- [ ] 性能优化（用户确认成品后再做）：高档约 400 万三角面；候选手段：稻丛/鱼群 LOD、远处植被合批、阴影分级。
- [ ] 开闸过程中若再走上下沉中的闸门，会随闸门落水（只在点击开闸瞬间转移玩家）。
- [ ] 直升机与高建筑只在离地 4 米内检测碰撞（手动飞行可能穿过住宅楼上部）。
- [x] 修复“泳池池壁冒出地面、别墅首层墙体浮空”：根因是 H125 尾桨叶片对 `box()` 返回网格调用了 `geometry.translate`，而 `BOXG` 为全体 box 共享，两次平移使之后烘焙的所有 box 构件整体上移自身高度的 0.93 倍（池壁 1.55 m→上移 1.45 m，首层墙 3.6 m→上移 3.35 m）。改为用枢轴组偏移叶片；**今后不要对 `box()` 返回网格的 geometry 做任何原地变换**。
- [ ] 直升机停机坪特写镜头下尾部比例待复核（尾桨已修正为以桨毂为中心、直径 1.86 m，其余部位未复核）。
- [ ] 游艇后甲板朝船尾方向的地面材质偏灰，待核对游泳平台材质。
- [x] boat_test 改为按 E 登船并用船体局部坐标重写船上路线；修复过程中发现并修正三处游戏问题：

  - 陆地漫游边界（|x|≤372、|z|≤222）在船上同样生效，游艇驶出该范围后人在船上无法走动 → 在船上时不限制。
- [ ] fp_shot.py 的 `deck` 预设传送时未带 onBoat 标志，截图时人落在水里，需补上。
- [ ] 各浏览器测试缺少断言，结果需人工对照基线；建议补断言并以非零退出码标记失败。

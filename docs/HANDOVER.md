4. 第三批需求：自动巡航（开闸→绕岛→回港靠泊→关闸）、蔬菜/大棚作物、泳池/湖/海水写实（半透明、焦散）。
5. 第四批需求：别墅盆栽（水仙/红玫瑰）、推拉门、精细家具、坐卧系统、iMac 书桌；全部水域可潜、瀑布粒子、鱼群、海豚互动；榕树整株化；游艇按 E 登离、缆绳改拴、舱内精细化与座位；沙滩纯白与连续坡度；H125 复刻与自动飞行；躺椅遮阳伞朝向；塔顶楼板；下沉式无围栏水闸。
6. 2026-09-24（新加坡时间）三水域生态（src/17a～17e_eco，全部热带物种、淡水与海水严格分开）：
   - 淡水湖：黄绿色水体、能见度 3～5 m、湖底卵石→沙泥（沉木挂藻、腐叶）→深色淤泥三层；芦苇、香蒲、睡莲（茎到湖底）、苦草/金鱼藻/黑藻/狐尾藻成丛；克氏原螯虾（尾扇后弹逃逸）、罗氏沼虾（雄虾蓝色长螯）、淡水蟹（卵石下躲藏、横走）、螺与河蚌、鲫鱼与罗非鱼（绕水草）。
   - 闸内潟湖：绿松石水体、能见度 15 m 以上、强焦散；白珊瑚砂、礁石、鹿角/脑/桌面珊瑚；泰来草、海菖蒲、马尾藻（带气囊）、仙掌藻；龙虾（洞口伸触角、无螯）、青蟹、章鱼（变色、贴底爬行、喷墨）、雀鲷/黄高鳍刺尾鱼/蝴蝶鱼/鹦嘴鱼、小丑鱼只在海葵附近；海星、海胆、海参；沙滩潮线贝壳（近水更密）与寄居蟹。
   - 外海：深蓝、远处雾化、随深度变暗、丁达尔光束；南侧金梭鱼龙卷（260 条）、东南沙丁鱼饵球（380 条，被虎鲸冲散后重聚）与虎鲸家族（7 头，编队巡游、追饵球）、西南座头鲸（3 头＋幼鲸，长胸鳍、跃身、换气）、北侧浪人鲹鱼墙（220 条，同步转向）与鲸鲨；虎鲸与座头鲸分区。
   - 技术：实例化网格＋两级 LOD、Boids（分离/对齐/聚合）＋避捕食者、按水域的雾色/能见度/焦散与闸口过渡、植物顶点着色器摆动随深度减弱、远处水域整体隐藏不计算；生态测试 `npm run test:ecology`。

# 截图巡检缺陷清单

`npm run shots` 生成 `reports/shots/sheet_*.png` 总览图后，逐张对照以下条目审阅。发现的问题按分类记入 `docs/ISSUES.md`，并注明截图编号。

## 视觉缺陷（错误，应修）
1. **悬空**：物体底部与地面或楼面之间有缝，在影子里尤其明显。
2. **埋地/陷入**：物体一部分沉进地面、楼板或水面以下；车轮、底座被切掉。
3. **穿插**：两个物体互相穿透，例如植物穿过墙或栏杆、家具穿过墙、车辆嵌进构件。
4. **共面闪烁**：两个面重叠，出现条纹或斑驳，移动视角时更明显。
5. **黑面/法线反转**：某个面整片发黑，或从背面才看得见。
6. **贴图错误**：拉伸、错位、缺失（洋红或纯白），重复纹理过于明显。
7. **缝隙/漏光**：墙角、楼板与墙之间透出天空或背景。
8. **比例异常**：门、台阶、栏杆、座椅、车辆相对人物比例不对。
9. **水面错误**：水面穿过地形、岸边露出水体侧面、水下物体不该露出却露出。
10. **阴影错误**：物体没有影子、影子和物体分离、阴影出现锯齿块。
11. **定稿约束被改**：设施位置、数量、道路走向与截图基线不一致（用 `npm run test:visual` 核对）。

## 审美建议（只记录，不自动改）
- 色调与材质不协调、过灰过暗、饱和度过高；
- 构图单调、大面积空白、植被过密遮挡主体；
- 细节密度不均（近景粗糙、远景过密）。

## 审阅要求
- 每张图都要看，不能只看自动初筛标了 ⚠ 的。
- 问题特写图（标题以"问题"开头）用来核实工具报出的问题：能在画面上确认的，在 ISSUES.md 标"截图核实"；确认是误报的，标"无需处理：检测误报"，并说明原因。

# 海面系统（05b_sea.js + 03b_shore.js）

减配移植自 [ShoreBreak](https://github.com/cryptomanavan/ShoreBreak)（© Christopher Canavan / awakewithai.com，MIT 许可）。以下代码片段来自 ShoreBreak 并保留其 MIT 声明：碎浪形态关键帧表与前坡形状函数、崩塌停顿时钟、弹道上冲模型、FFT 风浪谱（JONSWAP + 方向分布 + 级联分段）、LEAN 斜率统计。

## 结构

| 层 | 做法 | 位置 |
|---|---|---|
| 海岸坐标场 | 离岸有符号距离、离岸方向、近岸坡度、迎浪程度、程函方程求解的涌浪到达时间、沿岸静态噪声；后台线程产出半精度纹理 | `03b_shore.js` |
| 事件表 | 确定性的浪列（周期、浪组、类型、剥离），打包为 `uEvtA/uEvtB` | `SeaSchedule` |
| FFT 风浪 | 3 级联（41 / 7.3 / 1.37 m）；实数场打包为两次复数 FFT，不依赖多渲染目标（r160 可用）；斜率纹理带 mipmap 供 LEAN | `SeaFFT` |
| 涌浪 / 碎浪 | 形态关键帧表在海岸坐标系中求值：外海浪线绕岛折射；泊港沙滩（陡台阶）出现卷曲型碎浪 | `seaState()` |
| 崖岸拍浪 | 新增：崖面上涌、崖脚炸白、蕾丝向外漂散 | `seaState()` |
| 沙滩上冲 | 解析弹道上冲 + 涌潮 + 湿膜 | `seaState()` |
| 光学 | 沿折射路径的 Beer-Lambert，透明度 = 1 − (1 − F)·透射率；天空反射；LEAN 太阳高光；逆光浪面透光 | 片元着色器 |

## 画质档位

| 档位 | FFT | 级联 | 网格段数 | 同时在途浪数 | 到达延迟压缩 |
|---|---|---|---|---|---|
| high | 256² | 3 | 192 | 12 | 0.5 |
| mid | 256² | 3 | 160 | 10 | 0.45 |
| low | 128² | 2 | 128 | 8 | 0.35 |

不支持 WebGL2 浮点渲染目标的设备自动回退到原海面；地址加 `#oldsea` 可强制回退，`#seadbg` 显示泡沫（红）、蕾丝（绿）、浪顶白冠（蓝）通道。

## 常用调参（`SEA` 与 `SHORE` 常量）

- `SEA.height`：外海名义碎浪高度（默认 0.62 米）。
- `SHORE.lagoonGain`：浪经缺口和镂空闸门进入泊港后的比例（默认 0.62）。闸门改为实心时调到 0 即可让泊港恢复静水。
- `SHORE.swellDir`：涌浪传播方向，改动后海岸场会重新计算到达时间。
- `SEA.U10` / `SEA.windDeg`：FFT 风浪的风速和方向。
- 水色：片元着色器里的 `SIGMA`（吸收）和浅水、深水两个颜色。
